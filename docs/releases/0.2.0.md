# FloatingX-Harmony 0.2.0

首个标准语义版本的 fork 正式包。Android 行为基准为 FloatingX 2.3.7（a4b9dbf）。本版是明确能力范围的稳定交付，不表示所有 Android 场景完全等价。

## 本版内容

- 提供局部、应用内和受权限约束的系统浮窗；保留默认手势/边界模式，Android 对齐模式需显式开启。
- 包含 Android 边界、拖动释放、内容布局、窗口生命周期和原生输入适配；历史依据见 [对齐审计](../android-parity.md)。
- 新增子内容 requestDisallowInterceptTouchEvent，支持当前触摸序列禁止父接管及后续撤销。
- 避免对已成功识别器调用 preventBegin，恢复成功长按松手后的 END。
- 示例增加父子手势、多指、隐藏复位测试，并修复切换页签后旧测试浮窗遮挡。

## 已验证

293 项宿主测试通过。独立 Demo 在 Mate 80 Pro Max / HarmonyOS 7.0.0 API 26 验证了禁止/撤销父拦截、长按自然 END、多指停止规则、子按钮无误触和隐藏后复位。原生系统窗口显示、退后台保留与关闭已有设备记录。

这些是具体用例验收，不替代 Android 真机同序列对照，也不代表所有机型与业务均验收。详见 [手势复验记录](../gesture-followup.md)。

## 已知限制

- 父接管瞬间仍不能等价取消已成功的子长按/滚动；自然 END 不等于 Android ACTION_CANCEL。
- 任意自定义内容事件归属、更多多指组合及多 Stage/Pad 等场景仍需专项验证。
- Android 长按布尔返回值对应的触觉反馈尚未完全映射。
- 系统 AVOID_SYSTEM 依赖同显示器全屏主窗口的权威安全区；分屏/不同显示器明确不支持。
- CMP 系统浮窗渲染问题不在本版修复范围。

ANDROID_2 的整窗子触摸取消要求运行 API 20+；最低兼容 API 12 不代表旧系统支持全部高级手势。系统浮窗仍需要平台签名权限与运行授权。

## 包与接入

从本 fork 的 v0.2.0 Release 下载 floatingx-v0.2.0.har，校验 SHA256SUMS 后按本地 HAR 引用。公开 import 名仍为 floatingx；版本常量 FLOATINGX_VERSION 为 0.2.0。

未签名示例包不包含开发者证书或设备权限材料，不能直接视为可安装的商业设备签名包。包的实际编译 SDK、模式、源码 commit 和 SHA-256 以 manifest.json 为准。

本版没有自动升级任何消费工程。业务应在自己的分支替换固定版本 HAR、同步 lock 并回归；保留原包及接入提交用于回退。
